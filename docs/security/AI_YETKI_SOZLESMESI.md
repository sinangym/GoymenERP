# AI Destekli Yetki Sözleşmesi

Akış:

`Doğal dil talebi → rol/veri kapsamı taslağı → mevcut/önerilen fark → görev ayrılığı analizi → erişim örnekleri → süre → yönetici onayı → uygulama → audit`

AI:

- Yetkiyi kendi uygulayamaz veya onaylayamaz.
- Kullanıcının mevcut yetkisinden fazlasını kullanamaz.
- Riskli kombinasyonları ve şirket/depo sızıntısını açıklamalıdır.
- Kişi istisnasını mümkünse süreli önermelidir.
- Her öneride dayanak politika sürümünü göstermelidir.

Kritik yetkiler ikinci onaya bağlanabilir: yönetici, ödeme, dönem, toplu dışa aktarım, banka hesabı, yetki verme ve audit erişimi.
